# Wolfmark 0.2.0-dev.1

Development milestone for native document layout and offline exports. Stable
0.2.0 acceptance is not complete. Nothing is published by this development task.

- Keep Qt 6 Widgets, working Rust parsing/image functionality, and Cargo builds.
- Introduce Xmake as the preferred project command interface.
- Parse file URIs before percent-decoding reserved path characters.
- Route Open through a window-wide action and route file drops before editor text
  insertion. Support multiple picker selections and persisted recent documents.
- Add native paper-layout preview and page/style presets without altering source.
- Add native PDF/print and editable DOCX/ODT, standalone HTML, and text exports.
- Stop installer file-handler registration, including when legacy option flags
  request it. Clean only legacy entries matching the known installation path.
- Add opening, file-lifetime, export-package, and layout regression coverage.

See [development and acceptance](../development/wolfmark-0.2.0.md) for commands,
scope, limitations, and release gates. Existing physical Windows, accessibility,
and Linux acceptance requirements remain in force. EPUB, batch exports, and
named per-document profile libraries are not release claims.
