# Moonmark 0.1.0-dev.7

> Development prerelease. Moonmark is early software; keep backups of important documents and report reproducible issues at the Moonmark GitHub repository.

Moonmark is a native, viewer-first Markdown application for ordinary local files. The Windows x64 build uses Rust, C++20, Qt 6 Widgets, QTextDocument, and Comrak without a browser engine.

## Dev.7 highlights

- Open `.md`, `.markdown`, and `.txt` paths passed by Explorer or the command line, including spaces and Unicode.
- Retain multiple startup documents in one Moonmark process while still allowing independent processes.
- Ship a self-contained portable Windows x64 folder/ZIP with app-local Qt and MSVC runtime libraries.
- Ship a conventional Inno Setup installer using that same validated payload.
- Embed Moonmark product/version/publisher metadata and the approved application icon in the executable.
- Produce SHA-256 checksums for the exact release artifacts.
- Register conventional Windows Open With handlers without taking over the user's current defaults.
- Use distinct Moonmark document icons for Markdown and text shell entries.
- Store typed settings in the normal per-user config location, or beside the executable in portable mode.
- Check the public GitHub release feed conditionally and asynchronously when enabled, with a manual check in Settings.
- Require exact release assets and verify downloaded installers/portable ZIPs against `SHA256SUMS.txt` before handoff.

## Renderer capability

This prerelease includes native selectable rendering for CommonMark and deliberately supported GFM features: headings, emphasis and strike, links/reference links/autolinks, lists and tasks, quotes, tables, inline/fenced code with syntax highlighting and Copy, rules, local raster/SVG images, heading navigation, and broad desktop layout. Moonmark also supports deliberate local-path conveniences such as literal spaces, Unicode, `%20`, angle-bracket destinations, parent-relative paths, absolute paths, and `file:///` image references. Remote images remain disabled.

## Downloads

- `Moonmark-portable-win-x64.zip` — extract and run `Moonmark.exe`; it performs no machine-wide registration.
- `Moonmark-Setup-win-x64.exe` — conventional installer for Program Files, Installed Apps, Start Menu, optional Desktop shortcut, and optional Open With availability.
- `SHA256SUMS.txt` — SHA-256 hashes generated from the final artifacts.

The Windows build is currently unsigned, so Windows may show an Unknown publisher warning. No Authenticode claim is made.

## Known limitations

- This is not production-ready software.
- The setup executable is unsigned; Windows reputation protection may warn before installation.
- Elevated Program Files installation and the Explorer/Installed Apps visual surfaces still require final physical acceptance before publication.
- No single-instance shell routing exists; Explorer may open a new process.
- Remote HTTP/HTTPS images, executable raw HTML, editing, unattended/background installation, Linux release packaging, and Android UI are not included.
- Update delivery requires an HTTPS GitHub release with the exact documented asset names. Portable updates are downloaded and revealed for manual replacement; Moonmark does not overwrite a running portable installation.
- Windows x64 is the only packaged target in this prerelease.
